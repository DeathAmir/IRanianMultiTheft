## Asset sources evaluated for integration

- Kenney Prototype Kit — https://kenney.nl/assets/prototype-kit — CC0 1.0. 145 low-poly assets and animated characters. Attribution is optional; credit Kenney / kenney.nl.
- Quaternius Ultimate Animated Character Pack — https://quaternius.com/packs/ultimatedanimatedcharacter.html — CC0 1.0 as stated on the pack page; 52 animated characters. Attribution is optional; credit Quaternius.

The CC0 legal code is available at https://creativecommons.org/publicdomain/zero/1.0/legalcode. No third-party model, font, animation, or sound binary is currently copied into this repository. The current soldier, target, weapon, and arena geometry are procedural primitives authored for this project. Do not infer that the listed external packs have been imported. When assets are imported, add the exact pack/file, creator, source URL, license text or URL, retrieval date, and any required attribution here.

## Fonts

The game currently uses raylib's built-in default bitmap font. No external font file is bundled. If a font is added, prefer SIL Open Font License (OFL) families and include the exact font license and copyright notice alongside the font files.
